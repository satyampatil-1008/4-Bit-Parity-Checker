# 4-Bit Even-Odd Parity Checker

A simple **4-bit Even and Odd Parity Checker** designed using digital logic gates and simulated in **Proteus**.

The circuit uses **74HC86 XOR gates** to determine the parity of a 4-bit input. Two LEDs indicate whether the input contains an even or odd number of logic HIGH (`1`) bits.

---

## 📌 Project Overview

Parity checking is a simple error-detection technique used in digital electronics and communication systems.

In this project, a 4-bit binary input is given to a chain of XOR gates. The XOR gates calculate the parity of the input data.

The circuit provides two outputs:

- 🔴 **ODD PARITY LED** – ON when the number of `1`s is odd.
- 🟢 **EVEN PARITY LED** – ON when the number of `1`s is even.

The complete circuit was designed and tested using **Proteus Design Suite**.

---

## 🎯 Objectives

- Understand the concept of parity checking.
- Implement parity logic using XOR gates.
- Design a 4-bit parity checker using 74HC86 ICs.
